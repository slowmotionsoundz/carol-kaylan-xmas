# Carol & Kaylan — Christmas on the Sound

Restyled interactive itinerary in the Soundside aesthetic (dark, coral, DM Sans/Manrope, day rail + timeline).
Static site: index.html + styles.css + app.js (the island hero image is embedded in index.html as a data URI, so no binary assets are needed). Google Fonts is loaded from the CDN, so the page needs network for fonts.

Flights verified against the user's ticket screenshot (23 Nov 2026): BNA 23 Dec 17:30 → KEF 06:10+1, FI204 KEF 07:30 → CPH 11:45 (Terminal 2); return 27 Dec FI205 CPH 12:55 → KEF 15:25, FI825 KEF 17:10 → BNA 18:45. Economy Flex, 1x23kg bag each.
